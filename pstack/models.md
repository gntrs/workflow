# pstack model configuration

per role choices for pstack's own roles only. the agents cook spawns itself take their models from cook's table. read the installed pstack provider dispatch reference before dispatching a configured role. every documented role stays present. `inherit-parent` uses the parent model and still counts as one panel lane.

this file is yours. the installer creates it once and never writes it again. it ships with every role on `inherit-parent`, which runs whatever model the session runs. to pin a role, write the provider, model and effort your plan has, the same names as `## models` in `~/.claude/RULES.local.md`, for example `claude:<model>@xhigh`. a panel role takes a list, `claude:<model>@xhigh, claude:<second model>@max`: a second model family is optional there and never the only lane, so a panel does not stop when one model runs out of credits.
