# home

start here. this vault is the brain: what is open, what was decided, what you like, what was learned. the `brain` skill reads and files it, `dream` keeps it tidy. Obsidian opens it as is; any editor works.

open items across every project: [[now]].

## how it is laid out

| folder | holds |
|---|---|
| `projects/<repo>/` | one folder per repo: the hub `<repo>.md`, `<repo>-log.md`, `<repo>-tbd.md`, `plans/`, `research/`. copy [[_example]] to start one |
| `decisions/` | `YYYY-MM-DD-<slug>.md`, what was decided and why |
| `taste/` | what you like and do not, in your words: [[taste]] |
| `memory/` | lessons for future sessions, indexed in [[MEMORY]] |
| `systems/`, `people/`, `inbox/`, `sessions/`, `archive/` | made on first use |

## rules

- every note links its hub, and the hub links back.
- unique file names across the vault. a bare `[[log]]` resolves to whichever one Obsidian finds first.
- no secrets, ever. no personal data about other people beyond work context.
- nothing is deleted. superseded notes move to `archive/` with a link from what replaced them.
